# 案例：某 SPU 墨西哥站的销量与跟卖核查（脱敏版）

> 本案例记录 2026-11-06 至 2026-11-09 会话中已实际查看的操作和证据。销售数据截止 2026-11-07；11月9日再打开领星时会话回到登录页，因此没有加入11月8—9日的新数据。2025/2026 销量均取领星同一张报表的同期对比列。价格历史来自 Amazon 商品页上的卖家精灵插件，实时报价来自商品页；用户对自己调价时间和缺货状态的说明单独标注。
>
> **脱敏约定**：本文件中的店铺名、ASIN、SKU、品牌名、卖家名、绝对销量、绝对销售额与绝对价格均替换为占位符或比例。占位符**不代表真实值**，复现时须以自己账号中的实际数据为准。

## 占位符对照

| 占位符 | 含义 |
|---|---|
| `STORE_MX` | 该产品所在墨西哥站店铺 |
| `SPU_A` | 被核查的父商品（本文档内部代号） |
| `ASIN_PARENT` | 父 ASIN |
| `ASIN_C1`…`ASIN_C5` | 五个用于交叉核对的子变体 ASIN |
| `COMPETITOR_1` / `COMPETITOR_2` | 观察到的两个非自有报价方（FBM / FBA） |
| `PRICE_LOW` / `PRICE_MID` / `PRICE_HIGH` | 低价报价 / 自有 FBA 报价 / 高位报价 |
| `N%` | 比例类结论，保留原值用于演示方法 |

## 操作复现

1. 在[领星产品表现](https://xfg.lingxing.com/erp/productExpressionNew)选择北美－墨西哥站，确认店铺范围为全部店铺（本次结果涉及 `STORE_MX`），按 SPU 搜索 `SPU_A`，展开父商品子行。选择日期 `20XX-01-01` 至 `20XX-11-07`、指定币种、`显示同比`，横向滚动读取销量、订单、销售额及同期列。父 ASIN 为 `ASIN_PARENT`。不要预设这一账号中的店铺或控件布局在其他账号相同。

2. 分段查询并记录同期列；中间未单独导出的月份用「全期减去已查询区间」得到。核对子行合计等于父商品的全年销量与同期销量。**关键口径坑**：本次页面中主销量格显示的同比为 `-64.13%`，但用两列原始值（401 与同期 1,077）重算为 `-62.8%`，两者不是同一分母，不能混写。本案例所有同比均按表中的两列值重算。

3. 对照子 ASIN 打开 Amazon 墨西哥站的具体变体，查看卖家精灵历史图的 Buy Box、最低报价、FBA 报价及卖家数，在有日期提示的抽样点记录数值；再看实时卖家及配送方式。卖家精灵对这些曲线的[解释](https://www.sellersprite.com/v3/knowledge/feature/keepa-tips-of-extension)用于辨别指标，第三方历史图不是 Amazon 的逐笔成交记录。

4. 在领星订单中查自有订单价格。本次某变体在 20XX-09-21 有自有订单价格约 `PRICE_MID`，而历史图在相近时段出现更低的购物车价 `PRICE_LOW`。这说明本店仍可能出单；领星看不到其他卖家的订单，不能用本店订单表推算跟卖销量。

5. 检查变体库存、购买路径和页面内容。用户指出某颜色变体缺货后领星会自动跳转，不能把此现象记作跟卖证据。页面某处文案经核实存在语义风险（例：西班牙语洗涤说明中出现语义相反的词），它是待修正/核实的页面信息风险，未取得其影响转化的量化证据。未取得能将某项墨西哥站政策变更与本商品销量对应起来的证据。

6. 用户账号没有领星跟卖监控权限，故没有把该入口的空结果当作“无跟卖”，也不在后续核查中重复依赖它。

本次用于交叉核对的子 ASIN：`ASIN_C1`(黑-M)、`ASIN_C2`(黑-L)、`ASIN_C3`(黑-XL)、`ASIN_C4`(藏青-M)、`ASIN_C5`(军绿-M)。页面变体和目录状态会变，复查时重新核对颜色、尺码及 ASIN。

产品表现页还显示广告归因订单 299 单、总订单 399 单。**广告归因、自然单和总单的定义及同比栏基数需要进一步对齐**；本次没有按日的广告花费、流量与转化率，故没有将广告指标用于估算跟卖损失。

## 购物车证据（方向保留，价格脱敏）

- `ASIN_C1` 商品页卖家精灵历史图：前期抽样点均为 1 位卖家，Buy Box、最低报价、FBA 报价三者接近 `PRICE_HIGH`。
- 20XX-03-14 的抽样点开始出现 Buy Box 明显低于 FBA 报价（`PRICE_LOW` 对 `PRICE_HIGH`）；3月22日抽样点卖家数为 2。10月、11月的抽样点 Buy Box 仍低于自有 FBA 报价，卖家数 2。**这些点证明自有 FBA 报价在相应时点没有占据购物车；历史卖家身份尚无法核实。**
- 最终时点：Buy Box 略高于最低报价、等于自有 FBA 报价、卖家数 2。商品页面显示 `COMPETITOR_1` 的 FBA 报价占据购物车，`COMPETITOR_2` 的 FBM 报价更低。**该时点表明「报价更低」不等于「占据购物车」。**
- `ASIN_C2`、`ASIN_C3`、`ASIN_C4` 当前页面也核实存在两位非自有报价；此前是否、何时丢失购物车，未逐日核实。
- 某无实时跟卖报价的变体，历史图在若干时点显示卖家数 2；因此**不能把它当作全年从未被跟卖的对照组**。

## 判断（方法结论，不依赖绝对数字）

某变体的历史购物车被非自有 FBA 报价占据可以直接确认；其他卖家报价与销量下滑在时间上重合，因而**跟卖是下滑的有力解释之一**。尚不能从历史图确定当时获胜的卖家就是目前的报价方。

四条当时被跟卖的变体减少量占全 SPU 减少量的 **45.0%**；这是**损失分布**，不是跟卖造成的销量损失估计。其余 17 条也贡献了 55.0%，其历史跟卖状态、库存和投放未完整排除。某颜色变体的缺货/跳转已由用户指出，**不能归咎于跟卖**。

现有数据不能证明总减少量中有多少由跟卖直接造成，也不能确定跟卖是全部下降的主要原因。

要定量归因，需要按日、按子 ASIN 对齐自有 FBA 可售库存、购物车占有率、广告与自然流量、会话/转化率及跟卖报价/卖家身份。**领星仅能看到自有订单，无法从自有订单直接读出跟卖卖家的成交量。**

## 可复用的方法论要点

1. **先国家、再店铺**：选国家会把店铺选择重置为「全部店铺」，顺序错了白选。
2. **同比不能只看页面显示值**：主单元格百分比与同期列分母可能不同，必须用两列值重算。
3. **分段必须闭合**：分段之和要回到全期数，否则说明区间重叠或漏取。
4. **三种度量口径分开标注**：目录 SKU 数 / 有销量的子行数 / Amazon 当前可见变体数。
5. **购物车四个价必须分清**：Buy Box 价、最低新商品报价、最低 FBA 报价、卖家数。最低价 ≠ 购物车。
6. **自有订单 ≠ 跟卖者成交**：领星订单只覆盖自己店铺。
7. **三种结论强度分级**：①某时点购物车归属（报价可证）②跟卖与下滑相关（时间/变体吻合）③跟卖造成的具体损失量（需购物车占有率+库存+流量对照）。
